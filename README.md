# Pre-Owned Student Merchandise Portal


## Project Overview

Pre-Owned Student Merchandise Portal is a Java-based web application that allows students to buy and sell used items within a campus community.

Students can list their unused products and other students can purchase them at affordable prices.


## Features


### User Module

- User Registration
- User Login and Logout
- Secure Password Encryption
- Add Products
- Upload Product Images
- Search Products
- Filter Products by Category and Price
- Buy Products
- View Order History
- Manage Own Products



### Admin Module

- Admin Login
- Admin Dashboard
- View Registered Users
- View All Products
- Remove Products
